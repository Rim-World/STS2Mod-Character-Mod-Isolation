# Changelog

本文件遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与语义化版本。版本更新日志的详细记录在 `7.ChangeLog/`，本文件只保留面向使用者的摘要。

## [Unreleased]

### Added

- 项目文件体系：PRD、PLANS、DOCS、ADR、SDD、SPEC、ChangeLog、TMP、TEST、OUTPUT、TOOLS、PRIVACY。
- 可行性调研：角色模组识别 + 三层内容过滤方案。
- 三版本 API 对照：0.107.1、0.111.0、0.113.1。
- 隔离行为规范 0.1 草案。
- 隔离行为规范 0.2 草案：只隔离角色模组内容；新增角色模组自动识别与手动选择。
- 性能影响静态预估：启动、运行时与内存。
- 0.1.0 运行时骨架：入口、设置数据、动态补丁安装、日志、版本校验。
- 自动识别：`ModelDb.AllCharacters` + 具体 `CharacterModel` 子类扫描 + 程序集归属。
- 手动选择：仅隔离勾选集合，完全跳过自动识别。
- 卡牌、遗物、药水、遭遇、事件、先古、章节过滤。
- Orobas Sea Glass 角色列表局部过滤。
- RitsuLib 设置页、自动/手动模式、模组勾选列表、中简繁文案。

### Changed

- 过滤范围由「所有非游戏内容」改为「角色模组内容」；纯卡牌、纯遗物等非角色模组内容保留。
- 隔离来源改为自动/手动互斥；手动模式完全跳过自动识别，只隔离勾选模组。
- 新增 `RQ-019`、`ADR-007`、`008-M` 角色模组识别计划。
- v1 不实现严格生成出口过滤、多人开启开关与工坊上传；只交付本地包。
