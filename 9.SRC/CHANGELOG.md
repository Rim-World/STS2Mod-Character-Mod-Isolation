# Changelog

本文件遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与语义化版本。版本更新日志的详细记录在 `7.ChangeLog/`，本文件只保留面向使用者的摘要。

## [0.3.0] - 2026-11-23

### Added

- 模组角色局保护当前角色所属模组，隔离其他角色模组。
- `RunContext` 增加 `ProtectedModIds`、`IsolatedModIds`、`CurrentCharacterOwner` 与 `PolicyVersion`。
- 设置页自动状态增加「本局保护此模组」，手动勾选文案改为「作为角色模组」。
- 日志记录模式、当前角色归属、保护集、隔离集与策略版本。

### Changed

- 原版角色局仍然隔离全部角色模组内容。
- 手动模式把勾选模组视为角色模组集合；未勾选模组不参与过滤。
- 隔离集为空时不启用过滤，当前角色内容保留。

### Fixed

- `SourceCache` 只按源数组判断导致跨局串用：同一进程自动模式建缓存后，手动仅保护 Watcher 时 MGR 池仍返回 0。缓存现在按 `PolicyEpoch` 与设置版本重建。
- 0.113.1 的 `AllCards` 源缓存热路径读取 `PolicyVersion`，会在开局 UI 预暖期间反复刷新运行上下文并卡住。改用不触发上下文刷新的 `PolicyEpoch`。

### Verified

- 0.111.1：自动 MGR 局 `MGR 91 / Watcher 0`；自动 Watcher 局反向成立。
- 0.111.1：手动 `{MGRMod,Watcher}` 的 MGR 局通过；手动 `{MGRMod}` 的 MGR 局 `active=False reason=manual-no-other`。
- 0.111.1：两局缓存 Run B 的 MGR 池 91；0.3.0.0 加载、50 补丁、0 失败。
- 0.113.1：自动 Watcher 与自动原版摄政均 3 幕 49 层 victory，退出码 0；两局缓存 Run B 的 MGR 池 91。
- 0.113.1：自动 MGR 保护集审计通过；全跑被 MGR 自身的 `ShowChanneledNote` 越界异常中止。

### Known limits

- 直接读取 `ModelDb` 全局集合仍会看到其他角色模组内容。
- 飞溅、万花筒、Orobas、色彩哲学家与设置页视觉尚未在 0.3.0 逐项复跑。
- 0.113.1 的 MGR 完整局仍受 MGR 0.8.1 自身异常影响。

## [0.2.0] - 2026-11-17

### Added

- 自动模式设置页显示检测到的角色模组：名称、ID、分类、依据与本局过滤状态。
- 仅检测已启用模组；自动识别、手动列表、日志与缓存排除禁用模组。
- 自动模式设置页的空状态与重新检测刷新。
- 0.111.0 兼容目标与 RitsuLib 0.6.14 编译入口。
- 依赖最低版本提高到 RitsuLib 0.6.14；新增 `tools/check-ritsu-version.ps1` 检查本机版本与清单下限。
- 单 DLL 兼容 0.111、0.113 的构建说明。
- 同一 DLL 在 0.111.1、0.113.1 完成加载与 AutoSlayer；0.113.1 摄政 A10 胜利，`removed=1 kept=6`。
- 强制 MGR 角色局验证不隔离：`cmi_active=False reason=mod-character`，MGR 卡组与奖励保留。

### Changed

- 兼容范围改为 0.111.0、0.113.1；0.107.1 停止支持。
- 设置页自动模式只显示已启用且被识别为角色模组的条目；手动模式只显示已启用模组。
- 清单最低版本改为 0.111.0。
- 清单依赖最低版本改为 RitsuLib 0.6.14。

### Removed

- 0.107.1 兼容承诺。

- 0.1.0 运行时骨架：入口、设置数据、动态补丁安装、日志、版本校验。

### Changed

- 过滤范围由「所有非游戏内容」改为「角色模组内容」；纯卡牌、纯遗物等非角色模组内容保留。

- 新增 `RQ-019`、`ADR-007`、`008-M` 角色模组识别计划。

- 0.113.1 完整原版局：摄政、3 幕、victory、退出码 0；卡牌分类 717 个、模组归属 0，全部分类 0 残留。
