# 010-E 色彩哲学家事件卡池取证

- 建立时间：2026-11-17 05:30
- 对象：二层事件 `ColorfulPhilosophers`（色彩哲学家）
- 来源：`4.STS2-113.1Reference/decompiled/MegaCrit.Sts2.Core.Models.Events/ColorfulPhilosophers.cs`
- 结论：该事件只从硬编码的原版职业卡池生成奖励；本模组还会在卡池查询出口过滤角色模组卡牌。0.113.1 场景实测通过。

## 一、事件如何生成选项

`GenerateInitialOptions()` 做三件事：

1. 从 `CardPoolColorOrder` 读取职业卡池列表。
2. 与玩家 `UnlockState.CharacterCardPools` 求交集，并排除当前角色自己的卡池。
3. 最多保留 3 个选项。

`CardPoolColorOrder` 是事件源码中写死的列表：

| 版本 | 列表 |
|---|---|
| 0.107.1 | 死灵、铁甲、摄政、静默、故障 |
| 0.111.0 | 死灵、铁甲、摄政、静默、故障 |
| 0.113.1 | 死灵、铁甲、摄政、愚者、静默、故障 |

角色模组的卡池不在这个列表里。因此事件选项本身不会出现角色模组职业，即使没有本模组也一样。

## 二、本模组的角色集合过滤

`UnlockState.CharacterCardPools` 来自 `UnlockState.Characters`。

本模组的 `CharacterPatches.CharactersPostfix` 在以下条件同时成立时移除角色模组角色：

- 本局只有原版角色。
- 单人。
- 总开关与卡牌分类开启。
- `UnlockState` 属于当前局。

原版角色局中，MGRMod 的 `MgrCharacter` 被移除，`CharacterCardPools` 只含原版职业池。色彩哲学家仍满足 `IsAllowed`，因为原版非愚者职业池数量大于 1。

## 三、奖励卡牌如何生成

点击选项后：

```text
ColorfulPhilosophers.OfferRewards(pool)
  -> CardCreationOptions(pool)
  -> CardCreationOptions.GetPossibleCards(player)
  -> pool.GetUnlockedCards(player.UnlockState, ...)
  -> CardFactory.CreateForReward(...)
  -> CardReward
```

`OfferRewards` 只把当前选中的原版卡池放进 `CardCreationOptions`，并设置 `NoCardPoolModifications`。

本模组在 `CardPoolModel.GetUnlockedCards` 上安装后置补丁：

- 角色模组卡池：返回空集合。
- 原版卡池：移除卡牌类型归属为角色模组的卡牌。

因此即使某个角色模组把自己的卡注入了原版卡池，奖励查询仍会移除这些卡。

## 四、边界

- 角色模组直接替换 `ColorfulPhilosophers` 事件代码，或直接修改原版事件选项列表，不在本模组的通用隔离范围。
- 角色模组把原版卡牌模型本身改掉，而不是新增卡牌，不在本模组的归属过滤范围。
- 角色模组在 `CardFactory` 或 `CardReward` 之后再次注入卡牌，v1 未做消费端最后过滤；标准卡池注册路径不受影响。
- 0.107.1、0.111.0 尚未在运行环境复测；它们的硬编码列表少愚者池。
- 场景模式不会经过主菜单，`MainMenuReadyEvent` 不触发；本次测试由临时探针强制调用 `PatchRegistry.InstallAll()`。正式游戏从主菜单进入时由正常生命周期安装。

## 五、验证入口

游戏内验收时选择原版角色，进入二层事件「色彩哲学家」，确认：

- 选项只出现原版职业名称。
- 奖励只出现原版卡牌。
- 日志出现 `category=cards` 或 `category=card-pool` 的过滤记录。


## 六、0.113.1 场景实测

- 时间：2026-11-17 19:13
- 环境：游戏 0.113.1，MGRMod 0.8.1 已启用，本模组 0.1.0。
- 场景：临时探针启动新单人局，固定铁甲角色，执行 `event COLORFUL_PHILOSOPHERS`。
- 日志：`8.TEST/0.1.0/2026-11-17-1915-色彩哲学家-scenario-补丁已装.log`
- 全量日志：`8.TEST/0.1.0/2026-11-17-1915-色彩哲学家-scenario.stdout`

### 6.1 角色与卡池过滤

探针在事件生成前读取：

```text
[patches] installed=51 failed=0
[auto] built. mods=40 character=1
[auto] character=MGRMod kind=Character reason=已注册角色
[filter] category=characters removed=1 kept=6 reason=vanilla-run
[probe] unlock characters=[DEFECT,FOOL,IRONCLAD,NECROBINDER,REGENT,SILENT]
[probe] unlock pools=[DEFECT_CARD_POOL,FOOL_CARD_POOL,IRONCLAD_CARD_POOL,NECROBINDER_CARD_POOL,REGENT_CARD_POOL,SILENT_CARD_POOL]
```

MGRMod 的角色和卡池已被移除。

### 6.2 事件选项

```text
[probe] event=ColorfulPhilosophers owner=IRONCLAD allowed=True
[probe] options count=3
[probe] option key=...options.REGENT title=橙色
[probe] option key=...options.SILENT title=绿色
[probe] option key=...options.DEFECT title=蓝色
```

三个选项都是原版职业。没有 MGR 职业选项。

### 6.3 奖励卡牌

探针选择「橙色」后，`OfferRewards` 使用 `REGENT_CARD_POOL`。三组奖励共 9 张，全部是摄政原版卡：

```text
cards=[COSMIC_INDIFFERENCE,GLITTERSTREAM,CLOAK_OF_STARS]
cards=[ORBIT,DEVASTATE,SUPERMASSIVE]
cards=[MAKE_IT_SO,GUARDS,ARSENAL]
```

没有 `MGR_MOD_CARD_*`。场景退出码为 0。

### 6.4 测试探针的必要性

第一次场景运行在 19:11 通过 `event` 直接进入事件，日志显示 MGR 角色仍在 `UnlockState` 中。原因是 ScenarioRunner 在启动时直接开始新局，不经过主菜单，`Plugin.OnMainMenuReady` 未执行，补丁没有安装。

第二次运行由临时探针反射调用 `CharacterModIsolation.PatchRegistry.InstallAll()`，补丁安装 51 个后，过滤生效。该探针只用于测试，不进入正式发布物。
