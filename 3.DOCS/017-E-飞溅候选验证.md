- 建立时间：2026-11-18 01:21

- 目的：验证原版角色打出「飞溅」时，候选攻击牌只来自原版角色卡池。
- 关联计划：[009-M](../2.PLANS/009-M-111兼容与检测显示.md)
- 关联需求：RQ-002、RQ-005

## 一、实现路径

游戏 0.111.1 的 `Splash.OnPlay` 按以下顺序取牌：

1. 读取 `Owner.UnlockState.CharacterCardPools`；
2. 如果角色池多于一个，移除当前角色自己的卡池；
3. 对剩余卡池调用 `CardPoolModel.GetUnlockedCards`；
4. 只保留 `CardType.Attack`；
5. 调用 `CardFactory.GetDistinctForCombat` 抽 3 张；
6. 通过 `CardSelectCmd.FromChooseACardScreen` 选择 1 张；
7. 将选中的牌加入战斗手牌。

因此，「飞溅」不需要单独的补丁；它经过卡池查询出口。`AllCards` 源级过滤和 `GetUnlockedCards` 后置过滤都在这条路径上。

## 二、测试方法

测试探针 `AutoSlayProbe` 增加以下记录：

- `splash-audit`：开局按 `Splash.OnPlay` 的同一顺序枚举候选，记录候选总数、角色模组归属数与 ID；
- `splash-inject`：向起始牌组加入 5 张 `Splash`，让 AutoSlayer 实际打出；
- `splash-play`：`Splash.OnPlay` 前缀，记录实际出牌；
- `combat-generation-enter/result`：`CardFactory.GetDistinctForCombat` 的输入与输出，记录模组归属数；
- `splash-select`：`CardSelectCmd.FromChooseACardScreen` 的选择结果。

判定标准：

- `splash-audit isolated=0`；
- 实际 `combat-generation-enter isolated=0`；
- 实际 `combat-generation-result isolated=0`；
- 实际 `splash-select owner` 不是角色模组；
- 本局分类覆盖的 `cards` 为 0 个模组归属。
