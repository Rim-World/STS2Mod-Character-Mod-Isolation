## 四、AutoSlayer

- 首次启动时，临时测试闸门 `AutoSlayProbe` 的清单仍写 `min_game_version=0.113.1`，被 0.111.1 拒绝；AutoSlayer 未开始。
- 已将测试闸门最低版本改为 `0.111.0`，并用 111 程序集重新构建测试闸门。
- AutoSlayer 与禁用测试使用 111.1 程序集构建的 0.2.0 DLL。
- 第二次 AutoSlayer 使用 `--autoslay --seed=1 --mode=standard`，退出码 0，wall time 514 秒。
- 日志：`8.TEST/0.2.0/2026-11-17-2126-1111-autoslay-standard-seed1.stdout`
- 选择角色：摄政，A10。
- 过滤器：`category=characters removed=1 kept=5 reason=vanilla-run`；0.111 原版有 5 个角色，移除 MGRMod。
- 奖励卡：全程 `player=REGENT pools=[REGENT_CARD_POOL]`，没有 MGR 卡牌。
- AutoSlayer 在第 49 层达到最大楼层后主动放弃，并输给 Aeonglass Boss；这不是崩溃，也不是本模组的过滤失败。
- 测试闸门清单最低版本已改为 `0.111.0`；测试闸门已在全跑后移出 `mods`。
- 测试环境计数包含 `AutoSlayProbe`：`mods=36`、`enabled=35`；正式环境为 `mods=35`、`enabled=34`。
- AutoSlayer 决策段没有 `MGR_MOD` 内容引用；`MGR_MOD` 只出现在开局的注册日志。
- 日志中出现 AutoSlayer 自身的 `WorldEnvironment` 父节点错误；该错误来自 AutoSlayer/场景切换，不是本模组日志，未中断全跑。
