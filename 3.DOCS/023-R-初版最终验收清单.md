## 一、验收范围

本次验收回答三个问题：

1. 设置页是否可用、可读，自动识别结果是否正确显示。
2. 角色模组角色是否仍然出现在选人界面，并且可以游玩。
3. 原版角色局与角色模组局的短局体验，是否符合「原版局隔离全部角色模组内容；角色模组局保留自身内容」的目标。

本次验收不要求完整通关，不要求重新跑 49 层 AutoSlayer，也不要求验证所有卡牌、遗物、药水、事件、遭遇、先古与章节。上述内容已有自动化证据。

## 二、通过规则

- 必验项编号为 `A-01` 至 `A-09`。
- 必验项全部「通过」，才能判定「初版最终验收通过」。
- 任何必验项「不通过」，本次验收不通过；记录编号、实际现象与截图即可。
- 选验项编号为 `B-01` 至 `B-06`。选验项不阻塞 0.3.0 发布。
- 无法完成某项时，结果记为「未执行」，不得写成「通过」。
- 验收期间不要修改生产代码，也不要部署测试探针；先记录问题，再另行修复。

## 四、必验项

### A-01 启动与设置入口

**目的**：确认模组正常加载，设置页入口存在。

**操作**：

1. 启动游戏，进入主菜单。
2. 打开 RitsuLib 提供的模组设置入口。
3. 找到「角色模组隔离」页面。

**通过判据**：

- [ ] 游戏进入主菜单，没有加载错误弹窗。
- [ ] 设置入口可以打开。
- [ ] 页面标题显示「角色模组隔离」。
- [ ] 页面说明显示原版局隔离、角色模组局保留自身内容的说明。

**失败记录**：记录入口名称、页面是否空白、截图与报错文本。

### A-02 自动识别清单

**目的**：确认自动模式识别到两个角色模组，且没有误报。

**操作**：

1. 保持「识别方式」为「自动识别」。
2. 查看「检测到的角色模组」区域。
3. 对照「已启用模组」区域。

**通过判据**：

- [ ] 检测清单包含 `MGRMod`。
- [ ] 检测清单包含 `Watcher`。
- [ ] 两个条目都标记为角色模组；不显示「扫描失败」。
- [ ] 不在检测清单中的已启用模组，不应被错误标成角色模组。
- [ ] 主菜单状态下，状态文字为「已检测；进入适用对局后生效」或同义文案。
- [ ] 清单没有空白条目、重复条目或明显错位。

**解释**：主菜单还没有进入具体对局，因此这里只能显示「进入适用对局后生效」。进入原版局或角色模组局后，状态才会变成「本局隔离此模组」或「本局保护此模组（当前角色所属）」。

### A-03 通用设置与分类开关

**目的**：确认设置项完整、可操作，默认值正确。

**操作**：

1. 查看「通用」区域。
2. 检查总开关、识别方式、七个分类开关和详细日志。

**通过判据**：

- [ ] `启用隔离` 为打开状态。
- [ ] `识别方式` 显示 `自动识别`。
- [ ] `卡牌`、`遗物`、`药水`、`事件`、`遭遇`、`先古`、`章节` 全部打开。
- [ ] `详细日志` 关闭。
- [ ] 下拉框可以打开并收起，不遮挡其他控件。
- [ ] 修改任意一个开关后，页面不报错；验收结束前恢复默认值。

**解释**：分类开关决定哪些内容类别参与隔离。关闭某一类时，该类别的角色模组内容会保留；因此验收时应保持全开。

### A-04 设置页视觉与可读性

**目的**：确认实际界面没有重叠、截断或不可点击。

**操作**：

1. 在设置页从上到下滚动一次。
2. 打开一次「识别方式」下拉框。
3. 在中文界面检查所有标题、说明、状态文字。

**通过判据**：

- [ ] 中文标题与说明完整显示，没有被截断。
- [ ] 长文本没有覆盖开关、按钮或下一行内容。
- [ ] 复选框、开关、下拉框都能点击。
- [ ] 滚动条可用，页面底部内容可以到达。
- [ ] 页面切换或关闭后再次打开，没有残留错位。
- [ ] 不出现空白页、重复控件或「未知」占位文字。

**失败记录**：必须附截图；写明窗口分辨率、语言与页面位置。仅有不影响阅读的轻微留白问题，可记「通过，有视觉小问题」并在备注中说明。

### A-05 手动模式切换

**目的**：确认手动模式入口存在，且切回自动模式不报错。

**操作**：

1. 将「识别方式」从「自动识别」切换为「手动选择」。
2. 查看「已启用模组」区域。
3. 不要把任何模组长期留在勾选状态；如需勾选，勾选后再取消。
4. 切回「自动识别」。

**通过判据**：

- [ ] 切换后页面标题变为「已启用模组」。
- [ ] 已启用模组列表可见，至少包含 `MGRMod` 与 `Watcher`。
- [ ] 每个模组有「作为角色模组 · 名称」复选框，且可以勾选、取消。
- [ ] 勾选或取消不弹出错误。
- [ ] 切回自动模式后，检测清单重新出现。
- [ ] 关闭再打开设置页，模式仍为自动识别。

**解释**：手动模式跳过自动识别，把勾选模组当作角色模组。自动化测试已覆盖手动 `{Watcher}` 选择 MGR 的边界；本项只验证界面与切换。

### A-06 选人界面角色可见

**目的**：确认角色模组没有被本模组隐藏。

**操作**：

1. 从主菜单进入角色选择界面。
2. 查看可选角色列表。
3. 不要启动对局也可以完成本项。

**通过判据**：

- [ ] `MGR` 角色可见。
- [ ] `Watcher` 角色可见。
- [ ] 两个角色都可以被选中；选中后可以正常返回或继续。
- [ ] 原版六个角色仍然可见。
- [ ] 不需要禁用模组或重启游戏才能看到这些角色。

**失败记录**：记录缺失角色、是否只在特定滚动位置出现、截图。

### A-07 原版角色短局

**目的**：用真实界面确认原版局不会出现角色模组内容。

**操作**：

1. 选择一个原版角色，开始标准局；推荐使用摄政。
2. 完成开局先古事件。
3. 进入第一场战斗，查看卡牌奖励。
4. 查看第一个遗物、药水或事件；遇到哪一类就检查哪一类。
5. 不需要打到通关，前 3 层足够完成本项。

**通过判据**：

- [ ] 开局角色、初始牌组与初始遗物都是原版内容。
- [ ] 先古选项没有 `MGRMod` 或 `Watcher` 的角色专属选项。
- [ ] 第一场战斗的卡牌奖励没有 `MGRMod` 或 `Watcher` 的卡牌。
- [ ] 看到的遗物、药水、事件没有角色模组专属内容。
- [ ] 原版卡牌、遗物、药水与事件仍然正常出现。
- [ ] 没有崩溃、卡死或无法关闭的界面。

**解释**：本项是短局冒烟，不要求验证全部类别。只要在本次短局中看到一个角色模组内容，就记「不通过」。没有看到不代表所有路径都已覆盖，其余路径由 022-E 自动化结果覆盖。

### A-08 角色模组短局

**目的**：确认角色模组自身内容仍然可用，同时另一个角色模组被隔离。

**操作**：

1. 选择 `Watcher` 角色，开始标准局；`Watcher` 比 MGR 更适合本次短局。
2. 查看初始牌组、初始遗物和第一场战斗奖励。
3. 如果愿意，也可以改用 MGR 角色；MGR 完整局存在已知的上游异常，短局可接受。

**通过判据**：

- [ ] 角色可以正常进入对局。
- [ ] 初始牌组与初始遗物包含所选角色模组的内容。
- [ ] 第一场战斗奖励可以出现所选角色模组的卡牌；若未出现，不单独判失败，但初始牌组或初始遗物必须证明所选角色模组内容存在。
- [ ] 看不到另一个角色模组的专属内容。
- [ ] 原版内容仍然正常出现。
- [ ] 对局可以正常推进；不需要通关。
- [ ] 如果选择 MGR，遇到其自身的 `ShowChanneledNote` 异常时记录为「已知上游问题」，不要记为本模组失败。

**解释**：本项验证「保护当前角色模组、隔离其他角色模组」。Watcher 局中应保留 Watcher 内容，隔离 MGR；MGR 局方向相反。

### A-09 结束状态

**目的**：确认验收没有留下错误的设置或测试文件。

**操作**：

1. 退出当前对局，回到主菜单。
2. 重新打开 CMI 设置页。
3. 关闭游戏。

**通过判据**：

- [ ] `启用隔离` 仍为打开。
- [ ] `识别方式` 已恢复为 `自动识别`。
- [ ] 手动列表没有长期保留的勾选项；如需保留，记录具体 ID。
- [ ] 七个分类开关仍为全开。
- [ ] 游戏可以正常退出，没有卡死。
- [ ] 游戏 `mods` 下没有新增测试探针目录。

## 五、选验项

以下项目不阻塞 0.3.0 发布。没有时间可以不执行。

### B-01 设置持久化

重启游戏后检查：总开关、识别方式、分类开关与手动勾选是否保持。期望与关闭前一致。

### B-02 旧存档加载

加载验收前已有的存档或一份副本。期望：旧内容不被删除；新生成内容按当前设置处理。不要直接用唯一一份重要存档做实验。

### B-03 色彩哲学家实际奖励

进入色彩哲学家事件，选择一个原版职业选项，检查奖励牌。期望：奖励来自所选原版职业池，不含 MGR 或 Watcher 卡牌。自动化只验证了选项生成，没有验证点击后的奖励。

### B-04 0.111.1 交叉版本

切换到 `0.111.1`，重复 A-06 或 A-07。自动化已通过，选验项只用于人工确认。切换版本由用户手动完成。

### B-05 多人、随机角色

本次不把多人、随机角色纳入验收。已知边界：多人默认跳过；随机角色可能抽到角色模组角色，该局按模组角色处理。

### B-06 性能

记录启动到主菜单的时间，以及进入设置页的时间。没有硬性数值门槛；与未安装本模组时相比不应出现明显卡顿。

## 七、已知边界

以下现象不是本次验收失败：

- MGR 0.8.1 的 `ShowChanneledNote` 在 0.111.1 与 0.113.1 都会越界；CMI 不对其打补丁。
- 不隔离角色模组对原版代码的直接 Harmony 补丁。

- 不隐藏图鉴与卡牌库中的角色模组条目。
- 直接读取 `ModelDb` 全局集合仍可能看到其他角色模组内容；卡池过滤通过不等于全局读取隔离。
- 多人默认跳过。
