### 6.4 0.113.1 卡池源缓存修复

复现：0.113.1 的原版局打开 `FilterCards` 后，AutoSlayer 在 `Embarking` 后无 `[context] active` 与 `run-start` 审计；关闭 `FilterCards` 或关闭 CMI 主开关后能开局。

托管栈转储显示主线程在 `Loadout.UI.Screens.NGenericSelectScreen` 的 UI 预暖与 `MegaRichTextLabel.AdjustFontSize`。根因定位到 `PoolPatches.CardPoolSourcePostfix`：它在 `CardPoolModel.AllCards` 的热路径读取 `RunContext.PolicyVersion`，该属性会调用 `EnsureForCurrentRun`，在开局 UI 预暖期间反复刷新运行上下文，造成卡池源数组失效并拖住 UI。

修复：新增不触发上下文刷新的原始纪元 `RunContext.PolicyEpoch`，源缓存改读该字段；策略或设置变化仍会使缓存失效。

| 运行 | 设置 | 结果 |
|---|---|---|
| 修复前 | 手动 `{MGRMod}`，`FilterCards=true` | 卡在 Embarking，无 run-start |
| 修复前 | 关闭 `FilterCards` | 开局通过，证明卡牌过滤相关 |
| 修复前 | 关闭主开关 | 开局通过，证明 CMI 相关 |
| 修复后 | 手动 `{MGRMod}`，`FilterCards=true` | `[context] active=True`、`run-start`、`cards-source removed=3 kept=47`，开局通过 |

修复后的完整原版局见 6.3。
