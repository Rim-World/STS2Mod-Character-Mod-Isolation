## 一、方法

1. 读取游戏目录 `release_info.json`，确认版本与 commit。
2. 读取参考库结构：各版本 pck 解包、反编译、模组源码、诊断日志。
3. 用 `rg` 定位关键类型与方法：
   - 模组加载：`ModManager`、`Mod`、`ModManifest`
   - 内容注册：`ModHelper`、`CardPoolModel`、`RelicPoolModel`、`PotionPoolModel`
   - 角色与池：`CharacterModel`、`UnlockState`、`ModelDb`
   - 跨角色效果：`Splash`、`CardFactory`、`CardCreationOptions`
   - 章节内容：`ActModel`、`RoomSet`、`RunManager`
4. 读取上游模组源码：BaseLib、RitsuLib、LinkuraMod、ModTemplate、STS2RevertAnthony。
5. 读取同向前作：SplashExclusion、PrismaticGemFilter。
6. 用 `diff`/逐文件签名比对三版本 API。
7. 将结论写入 DOCS、ADR、SDD、SPEC，并建立 PRD/PLANS/ChangeLog 等文件体系。
