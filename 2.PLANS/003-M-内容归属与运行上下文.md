## 内容归属

### 输入

- `ModManager.GetLoadedMods()`：只返回 `state == Loaded` 的模组。
- `Mod.manifest.id`：稳定模组标识。
- `Mod.path`：模组目录。
- `Mod.assembly`（0.107.1）或 `Mod.assemblies`（0.111.0 起）：模组程序集。
- 模型类型：`CardModel`、`RelicModel`、`PotionModel`、`EventModel`、`EncounterModel`、`AncientEventModel`、`ActModel`、`CharacterModel`、各类池。

### 算法

1. 遍历已加载模组。
2. 读取 `assemblies` 字段；不存在时读取 `assembly` 字段。
3. 建立 `Assembly -> modId`。
4. 对未登记的程序集，用 `Assembly.Location` 是否位于 `Mod.path` 下做补充映射。
5. 仍未知的类型，用根命名空间与模组 ID/名称匹配做最后补充。
6. 游戏程序集 `typeof(ModelDb).Assembly` 视为原版。
7. 已知框架程序集（BaseLib、RitsuLib、Harmony、Godot、系统程序集）的辅助类型视为框架；框架程序集里的具体模型类型仍按非游戏程序集处理。
8. 其他非游戏程序集：按未知归属处理，不自动隔离，记录一次警告。
9. 按 `Type` 缓存归属结果。

### 输出

```csharp
enum ContentOrigin { Vanilla, Framework, Mod, Unknown }

static ContentOrigin GetOrigin(Type type);
static string? GetOwnerModId(Type type);
```

### 判定

| 条件 | 结果 |
|---|---|
| 不在局内 | 不隔离 |

| 全部玩家角色为原版，单机，总开关开 | 隔离 |
