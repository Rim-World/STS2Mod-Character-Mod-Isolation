# 008-M 角色模组识别与手动选择

- 层次：M
- 状态：进行中（0.1.0 代码已实现；0.3.0 手动勾选语义与当前角色保护由 [010-M](010-M-模组角色局保护当前模组.md) 接续）
- 说明：本文「有效集合严格等于勾选集合」只对应 0.2.0。0.3.0 起以 010-M 和 SPEC v0.6 为准。
- 建立：2026-11-17 03:05
- 更新：2026-11-17 03:30
- 目标：自动模式下识别角色模组；手动模式下完全跳过识别，只隔离用户勾选的模组。

## 输入

- 设置中的隔离来源：`Auto` 或 `Manual`。
- 手动模式：用户勾选的模组 ID 集合。
- 自动模式：
  - `ModManager.GetLoadedMods()`：已加载模组。
  - `Mod.manifest.id`、`Mod.manifest.name`：稳定标识与显示名。
  - `Mod.assemblies`（0.111+）或 `Mod.assembly`（0.107.1）：模组程序集。
  - `ModelDb.AllCharacters`：包含 BaseLib / RitsuLib 追加的模组角色。
  - `ModContentRegistry.TryGetOwnerModId`：RitsuLib 精确归属，可选。
- 两种模式都需要 `ContentOwnership.GetOwnerModId(Type)` 做内容归属。

## 算法

### 手动模式

1. 读取持久化的勾选集合。
2. 不读取 `ModelDb.AllCharacters`。
3. 不扫描 `CharacterModel` 子类。
4. 不构建自动分类。
5. 有效隔离集合 = 勾选集合。
6. 勾选为空 → 不隔离任何内容。
7. `ContentOwnership` 仍构建，用于知道内容属于哪个勾选模组。

### 自动模式

1. 所有模组加载完成后执行。
2. 读取 `ModelDb.AllCharacters`。
3. 对每个角色类型：
   - 游戏程序集：跳过。
   - 非游戏程序集：按程序集归属找到模组，标记为「已注册角色」。
4. 补充扫描每个模组程序集中的具体 `CharacterModel` 子类：
   - 非抽象、非泛型、非框架程序集。
   - 未注册的标记为「可能角色」；默认按角色模组处理。
5. 没有角色证据的模组标记为「非角色模组」。
6. 归属失败或读取失败标记为「未知」。
7. 未知项默认不隔离；日志警告。
8. 自动结果按模组 ID 缓存。

## 设置页

- 隔离来源：自动识别 / 手动选择，二选一。
- 自动模式：显示自动分类与依据；只读。
- 手动模式：列出所有已加载模组，提供勾选框；只隔离勾选项。
- 手动模式不显示自动分类，也不运行自动识别。
- 模式与勾选列表持久化，下一局生效。
- 提供「重新检测」按钮，仅在自动模式可用。

## 测试

| 场景 | 预期 |
|---|---|
| 自动模式，标准角色模组 + 纯卡牌模组 | 只识别角色模组；纯卡牌模组放行 |
| 自动模式，未注册角色类 | 可能角色；默认按角色模组处理 |
| 自动模式，未知归属 | 不自动隔离；日志 |
| 手动模式，勾选角色模组 A | 只隔离 A；不读取 `ModelDb.AllCharacters` |
| 手动模式，勾选纯卡牌模组 B | 只隔离 B；即使 B 没有角色 |
| 手动模式，勾选为空 | 不隔离任何内容；自动识别不启动 |
| 手动模式切换到自动模式 | 下一局重新执行自动识别 |
| 自动模式切换到手动模式 | 下一局不执行自动识别 |

## 风险

| 风险 | 处理 |
|---|---|
| 手动勾选漏掉依赖模组 | 设置页显示模组列表；文档说明 |
| 手动勾选纯内容模组 | 用户可以按意愿隔离；不做二次判断 |
| 共用程序集归属歧义 | 归属失败内容不自动过滤；日志 |
| 自动模式读取 `ModelDb.AllCharacters` 过早 | 延迟到所有模组加载完成 |
| 手动模式误以为仍会自动补全 | 设置页明确说明「只隔离勾选」 |

## 完成判据

- 自动模式能区分标准角色模组与纯卡牌模组。
- 手动模式完全跳过自动识别。
- 手动模式只隔离勾选集合；空集合不隔离。
- 模式与勾选列表持久化，下一局生效。
- 日志能说明当前模式与手动勾选数量。
