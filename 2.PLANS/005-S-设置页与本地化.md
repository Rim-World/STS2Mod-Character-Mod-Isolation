# 005-S 设置页与本地化

- 层次：S
- 状态：进行中（0.1.0 代码已实现；0.3.0 手动语义与状态由 [010-M](010-M-模组角色局保护当前模组.md) 接续）
- 说明：本文「只影响原版角色局」「只隔离勾选模组」的描述只对应 0.2.0。0.3.0 起以 010-M 和 SPEC v0.6 为准。
- 建立：2026-11-17 02:16
- 目标：让玩家不用改文件即可控制隔离，并让设置可持久化、中英文可读。

## 设置项

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `master_enabled` | bool | true | 总开关 |
| `filter_cards` | bool | true | 卡牌与卡池 |
| `filter_relics` | bool | true | 遗物 |
| `filter_potions` | bool | true | 药水 |
| `filter_events` | bool | true | 事件与遭遇 |
| `filter_ancients` | bool | true | 先古与章节 |
| `verbose_log` | bool | false | 详细日志 |

## 交互

- 设置页标题写明「原版角色隔离」。
- 说明文字写明：只影响原版角色局；模组角色局不受影响；不隔离模组对原版代码的补丁。
- v1 不提供多人开启开关；多人会话直接跳过。
- 设置变更在下一局生效；局内变更不得改变本局判定，避免中途状态发散。

## 持久化

- 若依赖 RitsuLib：使用 `ModDataStore`，`SaveScope.Global`，设置模型为 class、无参构造、属性。
- 若不依赖 RitsuLib：使用模组目录下 `settings.json`，读取失败回默认值，写盘失败只记录日志。
- 设置架构版本号；结构变更时整体重置或迁移，迁移规则写入 SPEC。

## 本地化

- `localization/eng.json`、`localization/zhs.json`。
- 键名固定，发布后不改名。
- 文案避免「可能」「大概」；写明作用范围与限制。

## 完成判据

- 设置页可见、可改、重启后保留。
- 关闭总开关后原版局恢复角色模组内容。
- 多人会话默认跳过。
- 中英文案无未翻译键。

## 逐模组角色模组覆盖

- 列出所有已加载模组：显示名、ID、自动分类、依据。
- 隔离来源：自动识别 / 手动选择。
- 手动模式列出所有模组并允许勾选；只隔离勾选项；不启动自动识别。
- 未知项醒目提示；默认不隔离。
- 覆盖持久化，按模组 ID 键控，下一局生效。
