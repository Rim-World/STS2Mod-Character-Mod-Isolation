## 一、背景

0.113.1 AutoSlayer 全跑与色彩哲学家场景实测已通过。当前仍有以下待确认项：

1. 兼容范围从 0.107.1、0.111.0、0.113.1 缩为 0.111.1、0.113.1。用户确认不单独复测精确 0.111.0。
2. 自动模式设置页需要显示被检测并触发过滤的角色模组。
3. 自动识别和设置页只处理已启用的模组；安装但禁用的模组不得进入检测。

当前代码枚举 `ModManager.GetLoadedMods()`，设置页直接列出这些模组。需要确认加载器是否已经排除禁用模组；无论结果如何，施工时必须用 `SettingsSave.ModSettings.IsModDisabled` 做显式校验，避免不同加载器或加载顺序导致禁用模组进入缓存。

### 2.2 自动模式显示过滤清单

设置页自动模式增加检测结果区，只显示已启用且被识别为角色模组的模组。

每项至少显示：

- 模组名称；
- 模组 ID；
- 自动分类：`Character` 或 `LikelyCharacter`；
- 过滤状态：本局已触发过滤、已检测但本局未触发、未检测到角色证据；
- 过滤原因或本地化说明。

空状态必须明确写出「没有检测到已启用的角色模组」。重新检测后立即刷新。手动模式仍显示勾选列表，不显示自动分类。

过滤状态的数据来源必须是当前的 `RunContext` 和 `CharacterModRegistry`，不得在设置页重新实现一套角色判定。设置页关闭或切换模式后，下一局仍按既有规则生效。

### 2.3 只检测已启用的模组

- 自动识别、手动选择列表、设置页自动清单、日志与自动分类缓存只包含已启用模组。
- 判断来源优先使用 `SettingsSave.ModSettings.IsModDisabled(mod.manifest.id, mod.modSource)`；同时保留对 `ModManager.GetLoadedMods()` 的兼容读取。
- 禁用模组不得进入 `ModelDb.AllCharacters` 扫描、程序集扫描、`Auto` 缓存、日志或设置页清单。
- 已有缓存中的禁用模组记录必须在重检测时清除。
- 手动勾选集合中的禁用模组 ID 可以被保留但不参与过滤，设置页应显示为不可用或移除；施工时选择一种一致行为并写入 SPEC。

## 三、施工步骤

### 阶段 P1：兼容基线

1. 准备 0.111.0 运行环境与 `sts2.dll`。
2. 对照 `2.STS2-111Reference/decompiled` 与 0.113.1 的程序集，更新 `3.DOCS/003-E` 的两版 API 表。
3. 更新清单最低版本、README、构建参数与依赖说明；运行 `9.SRC/tools/check-ritsu-version.ps1` 检查 RitsuLib 最新版。
4. 在两个版本分别做无头启动，确认 51 个补丁和设置页注册。
5. 分别跑一次 AutoSlayer 标准模式；记录版本、种子、结果。
6. 只在两版都通过后，才把 RQ-009 标为已实现。

### 阶段 P2：已启用模组筛选

1. 在 `CharacterModRegistry` 增加统一的已启用模组枚举入口。
2. 让 `LoadedMods()`、自动分类、`GetAssemblies` 扫描与设置页候选列表使用同一入口。
3. 在 `EnsureAuto`/`RescanAuto` 清理禁用模组缓存。
4. 增加日志：已启用模组数、跳过禁用模组数；日志不得输出玩家隐私。
5. 验证禁用 MGRMod 后，自动识别不出现 `MGRMod`，设置页不列 MGRMod。

### 阶段 P3：设置页显示

1. 在 `ModSettings.AddModsSection` 分离自动检测结果与手动勾选列表。
2. 自动项使用 `CharacterModRegistry.GetAuto`/`DescribeAuto` 和 `RunContext` 生成状态。
3. 增加「重新检测」的刷新测试。
4. 补齐三语言本地化键：`zhs`、`zht`、`eng`。
5. 检查空状态、长模组名、中文/英文混排、禁用模组隐藏。

### 阶段 P4：验收

1. 0.111.0、0.113.1 无头加载。
2. 0.111.0、0.113.1 AutoSlayer 各一次。
3. 自动模式设置页：已启用 MGRMod 显示名称、ID、分类、过滤状态。
4. 禁用 MGRMod：不显示、不检测、不进入日志。
5. 手动模式：只列已启用模组；禁用项不可勾选。
6. 原版角色局过滤仍通过；模组角色局不隔离。
7. 更新 `8.TEST` 登记与 `3.DOCS` 证据。
8. 同一份 DLL 在 0.113.1 复测；不重新构建。
