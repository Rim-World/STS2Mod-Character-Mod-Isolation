## 结论摘要

1. 对「按标准方式注册内容」的第三方角色模组，按本局角色集合做运行期内容过滤是可行的。
2. 最关键的三个过滤层是：`UnlockState.Characters`、`CardPoolModel.GetUnlockedCards` 等池查询出口、`ActModel` 的内容列表出口。
3. 「飞溅」不需要重写方法；过滤角色卡池集合与卡池查询结果即可让它只看到原版卡。
4. 不能隔离直接修改原版代码的 Harmony 补丁；这是方案边界。
5. 单程序集兼容三版本在 API 层面可行；`Mod.assembly` 与 `Mod.assemblies` 差异用反射吸收。
6. 多人模式默认关闭；旧存档内容不清理；过滤失败安全降级。
