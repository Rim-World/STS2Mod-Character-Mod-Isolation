# 006-S 诊断与失败降级

- 层次：S
- 状态：进行中（0.1.0 代码已实现；验收待完成）
- 建立：2026-11-17 02:16
- 目标：过滤出错时不崩溃、不静默、可定位。

## 日志字段

| 时机 | 级别 | 内容 |
|---|---|---|
| 初始化 | Info | 模组版本、游戏版本、依赖是否就绪 |
| 归属映射构建 | Info | 已加载模组数、程序集数、未知程序集数 |
| 每局开始 | Info | 角色集合、是否隔离、原因 |
| 首次过滤 | Info/Debug | 类别、输入数、移除数、保留数 |
| 未知归属 | Warn | 程序集名、首次出现的类型、不自动隔离的决定 |
| 角色模组识别 | Info | 模组 ID、自动分类、依据、当前模式、手动勾选数量 |
| 补丁失败 | Error | 补丁 ID、目标方法、异常类型与消息 |
| 过滤异常 | Error | 类别、异常；同一类别限流 |
| 多人跳过 | Info | 网络类型、跳过原因 |

## 失败降级

1. 所有过滤方法外层 `try/catch`。
2. 异常时返回原结果，不返回空集合。
3. 核心补丁失败：整体关闭隔离，设置页显示「未生效」。
4. 分类补丁失败：只关闭该分类。
5. 归属映射失败：视为未知归属，不自动隔离；日志 Error。
6. 运行状态读取失败：视为不在局内，不过滤。
7. 设置读取失败：使用默认值，日志 Error。

## 隐私

- 不记录玩家账号、Steam ID、存档路径中的用户名。
- 只记录模组 ID、类型名、数量、游戏版本。
- 日志写入游戏日志系统，不额外写游戏目录。

## 完成判据

- 人为制造一个过滤异常，游戏不崩溃，日志有记录。
- 人为移除一个补丁目标，日志写明补丁 ID，其余功能按策略工作。
- 关闭详细日志后，常规局不刷屏。
