# 需求索引

## 项目

- 名称：角色模组隔离（Character Mod Isolation）
- 本地目录：`STS2Mod-角色mod屏蔽`
- 载体：Slay the Spire 2 模组（Godot 4 + .NET 9 + Harmony）
- 一句话目标：第三方角色模组保持启用，选人界面仍可选；游玩原版角色时，该模组新增的卡牌、遗物、药水、事件、遭遇、先古与章节不进入本局内容。
- 当前阶段：0.1.0 已实现；0.113.1 主菜单、手动模式、色彩哲学家场景与 AutoSlayer 全跑通过。兼容目标已改为 0.111.0、0.113.1；0.107.1 不再支持。自动模式过滤清单、仅检测已启用模组、111/113 兼容的施工计划见 [2.PLANS/009-M](../2.PLANS/009-M-111兼容与检测显示.md)；本轮不施工。

## 非目标

- 不卸载、不禁用、不删除第三方角色模组。
- 不把原版角色运行伪装成「未安装模组」的运行；模组仍加载，全局补丁仍生效。
- 不隔离第三方模组对原版内容的直接代码补丁。例如修改原版卡牌数值、修改原版遗物逻辑、替换原版界面。这类改动不是「新增内容」，无法按内容归属过滤。
- 不保证与所有 Harmony 补丁型模组兼容。只保证按标准内容注册方式添加内容的角色模组。
- 不清理已有存档里的模组卡牌、遗物、药水或事件。隔离只影响新生成内容。
- 不在 v1 承诺多人模式隔离。默认在多人会话中关闭。
- 不隐藏主菜单图鉴、卡牌库、遗物图鉴中的模组条目。是否隐藏属于界面需求，另行决定。

## 验收用例

| 编号 | 场景 | 预期 |
|---|---|---|
| AC-01 | 安装一个标准角色模组，选原版铁甲战士，打出「飞溅」 | 候选只含原版角色攻击牌；无该角色模组的攻击牌 |
| AC-02 | 同上，连续查看 5 次战斗奖励与 3 次商店 | 无该模组卡牌、遗物、药水 |
| AC-03 | 同上，走过事件、精英、Boss、先古节点 | 无该模组的事件、遭遇、先古、章节内容 |
| AC-04 | 选该模组角色开始新局 | 该模组的卡牌、遗物、药水、事件按原行为出现 |
| AC-05 | 关闭隔离总开关，选原版角色 | 角色模组内容恢复出现；纯内容模组行为不变 |
| AC-06 | 保存并重新加载原版角色局 | 不崩溃；既有内容不丢失；新生成内容仍隔离 |
| AC-07 | 多人会话（默认配置） | 隔离不启用；日志说明原因 |
| AC-08 | 0.111.0、0.113.1 分别启动 | 模组加载；无缺失成员异常；原版内容可正常生成 |
| AC-09 | 同时安装一个标准角色模组与一个纯卡牌模组，选原版角色 | 只隐藏角色模组内容；纯卡牌模组内容正常出现 |
| AC-10 | 切换到手动选择模式，勾选一个模组，开始新局 | 自动识别不启动；只隔离勾选模组；未勾选内容保留 |
| AC-11 | 自动模式打开设置页，MGRMod 已启用并识别为角色模组 | 页面列出 MGRMod 的名称、ID 和过滤状态；只列已启用模组 |
| AC-12 | 安装但禁用另一个角色模组，再进入设置页 | 禁用模组不出现在自动检测清单；日志与自动分类不包含该模组 |

验收用例的联合执行计划见 [2.PLANS/002-G-实现与三版本验证.md](../2.PLANS/002-G-实现与三版本验证.md) 与 [2.PLANS/009-M-111兼容与检测显示.md](../2.PLANS/009-M-111兼容与检测显示.md)。
