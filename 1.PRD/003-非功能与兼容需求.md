## RQ-015 性能开销可接受

- 优先级：低
- 验收标准：归属映射与角色模组识别在首次使用时构建一次，之后按类型与模组缓存。单次卡池查询的额外工作与候选数量线性相关，不重建卡池、不扫描全部程序集。运行策略变化时，只重建受影响的过滤缓存；不得用进程级缓存保存上一局的有效隔离集。启动额外开销目标不超过 200 毫秒；单次内容查询目标不超过 0.1 毫秒；详细日志关闭时，发牌、商店、事件生成不得出现可感知卡顿。预估依据见 [007-R](../3.DOCS/007-R-性能影响预估.md)。
- 状态：未开始
- 来源：报告结论

- 状态：已实现（单 DLL、单清单；修复后的 DLL 尚未在 0.113.1 复测）
- 来源：用户要求（2026-11-17）、报告结论

## 外部约束

| 约束 | 内容 | 影响 |
|---|---|---|
| 游戏版本 | 0.111.0、0.113.1 | 只用两版一致成员；差异成员反射 |
| 0.107.1 | 用户放弃支持 | 不再作为开发与验收目标 |
| 0.113.0 | 参考库标记弃用 | 不作为验收目标 |
| 运行时 | Godot 4.5.1、.NET 9、Harmony | 模组 DLL 加载到默认 AssemblyLoadContext |
| 程序集留存 | 已留存 0.111.1 运行程序集到 `2.STS2-111Reference/assemblies/sts2.dll`；0.111.0 反编译源码可用 | 施工前确认编译基线与最低支持 API |
| 模组加载 | 只加载 `<mod_id>.dll`；不能卸载 | 不能用「按局卸载」实现隔离 |
| 内容缓存 | 池首次访问后缓存 | 在查询出口过滤，不重建池；策略变化时重建过滤结果 |
| 多人 | 本地设置不同步 | 默认关闭，避免状态发散 |
| 存档 | 已有内容不清理 | 只过滤新生成内容 |

## 兼容性策略

1. 兼容目标为 0.111.0 与 0.113.1；0.107.1 不再支持。
2. 施工时重新确认编译基线；优先使用最低支持版本 0.111.0 的程序集，若运行环境不具备，则继续用 0.113.1 编译并只调用两版一致成员。
3. 运行期只调用 [3.DOCS/003-E](../3.DOCS/003-E-三版本API对照.md) 中确认对 0.111、0.113 可用的成员；差异成员用反射处理。
4. `Mod.assemblies` 等加载器字段通过反射读取，不直接依赖具体版本字段形状。
5. 不引用只在 0.113 存在的类型或枚举值，除非有显式版本守卫并完成两版验证。
6. 章节生成按版本补丁 `GenerateRooms` 存在的重载；代码不得直接调用该方法，避免编译期绑定到单一签名。
7. 所有补丁目标用名称与参数类型定位，找不到时记录并跳过，不阻断其他补丁。

## 失败与降级

| 情形 | 行为 |
|---|---|
| 角色模组集合为空 | 不隔离；日志警告 |
| 某类型程序集未知且非游戏程序集 | 按未知归属处理，不自动隔离；日志记录一次，设置页提示切换手动选择模式 |
| 某补丁应用失败 | 记录补丁 ID；核心补丁失败时整体关闭隔离，避免半过滤 |
| 过滤方法抛异常 | 捕获并返回原结果；日志记录一次，限流 |
| 运行状态读取失败 | 视为不在局内，不过滤 |
| 多人会话 | 默认不过滤；日志写明原因 |
