# 010 保护当前角色模组并隔离其他角色模组

- 状态：已接受（0.111.1 验证通过；0.113.1 运行时待验证）
- 日期：2026-11-23
- 当时项目版本：0.2.0
- 相关文件：[施工计划](../2.PLANS/010-M-模组角色局保护当前模组.md)、[可行性报告](../3.DOCS/018-R-模组角色局隔离其他角色模组可行性.md)、[功能需求 RQ-022](../1.PRD/002-功能需求.md)、[隔离行为规范 v0.6](../6.SPEC/001-隔离行为规范-v0.6.md)、[总体设计](../5.SDD/001-总体设计草案.md)

## 背景

旧实现把运行状态分成二元状态：原版角色局启用过滤；本局任一玩家角色来自模组时不启用过滤。该行为满足「模组角色正常游玩」，但不满足多角色模组环境下的内容隔离。

用户要求：

- 自动模式下，原版角色局隔离全部角色模组内容。
- 自动模式下，游玩角色模组 A 的角色时，保护 A 的内容，隔离其他角色模组的内容。
- 原版内容不被隔离。
- 手动模式下，用户勾选的模组被视为角色模组，并执行相同行为。
- 选人界面保持全部角色可见、可选。

现有过滤链已经按内容类型归属到模组。问题集中在运行上下文和过滤入口：`RunContext` 遇到模组角色直接停用，`FilterPolicy` 只判断「是否角色模组」，没有「当前角色所属模组」的保护集。

## 决策

把「是否角色模组」和「本局是否隔离」拆成两个问题。

定义：

- `C`：本局适用的角色模组集合。自动模式取自动识别结果；手动模式取用户勾选集合。
- `O`：当前角色所属模组。原版角色为 null。
- `P`：保护集，等于 `{O}`（当 `O` 非空），否则为空。
- `I`：隔离集，等于 `C − P`。

运行策略：

1. 原版角色局：`P` 空，`I = C`，隔离全部角色模组。
2. 角色模组 A 局：`P = {A}`，`I = C − {A}`，保留 A，隔离其他角色模组。
3. `I` 为空时，不启用过滤；当前角色内容保留。
4. 手动模式只把勾选模组放入 `C`；未勾选模组不参与过滤。
5. 原版内容不进入 `C`，因此不会被隔离。

过滤入口统一使用「内容归属模组 ID 是否在 `I` 中」。不再由 `CharacterModRegistry.GetIsolatedOwner` 单独回答本局是否过滤。

缓存必须带策略版本。同一进程切换原版局、A 局、B 局时，卡池源过滤结果必须重建。

## 备选方案

| 方案 | 否决理由 |
|---|---|
| 保持旧行为：模组角色局完全不隔离 | 不满足多角色模组隔离需求 |
| 模组角色局隔离全部角色模组，包括当前角色模组 | 会删除当前角色的起始牌组、卡池、遗物、事件；角色不可玩 |
| 隐藏其他角色模组角色 | 改变选人界面；用户明确要求保持可见、可选 |
| 按当前角色内容白名单逐个保留 | 需要枚举全部当前内容；扩展新内容时容易漏；维护成本高 |
| 自动与手动各写一套过滤规则 | 行为分叉；测试矩阵翻倍；缓存与日志不一致 |
| 保护当前角色模组及其所有声明依赖 | 可能保留其他角色模组内容；依赖关系语义与角色模组分类不一致；本轮先按当前角色所属模组保护，归属分裂由 P0 审计处理 |

## 后果

**获益**

- 原版角色局行为不变。
- 模组角色局可以同时安装多个角色模组，只看到当前角色模组与原生内容。
- 手动模式语义统一：勾选即角色模组，不再只是「隔离名单」。
- 选人界面不改变，角色模组仍可选。

**代价**

- 当前角色内容如果由其他模组 ID 拥有，保护集会不完整。P0 必须先审计；未解释的分裂作为阻塞项。
- `FilterPolicy` 的中心判定必须替换；不能只改 `RunContext`。
- `SourceCache` 必须失效；同一进程连续局的回归成本增加。
- 设置页状态和日志需要新增「保护集」「隔离集」语义。
- 随机角色、多人模式仍不在本轮范围。

**下游规则**

1. 过滤只允许使用 `RunContext.IsolatedModIds` 或待定的隔离集。
2. 当前角色所属模组不得被加入隔离集。
3. 原版角色局不得保护角色模组。
4. 手动模式未勾选的模组不得进入 `C`。
5. 不得硬编码角色模组 ID、角色名或卡牌名单。
6. 策略变化必须递增 `PolicyVersion`，并重建源过滤缓存。
7. 选人界面不得使用运行期保护集过滤。
8. 随机角色、多人模式继续按既有规则跳过。
